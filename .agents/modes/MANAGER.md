# Manager Mode

> **Note:** Prefer updating `AGENTS.md` and mode guides directly. Keep extra notes minimal and store temporary artifacts in `/tmp/agents-artifacts/`.

## Purpose

Managers maintain contributor instructions, process alignment, and cross-mode clarity.

## Guidelines

- Run mandatory preflight and run-log steps from root `AGENTS.md`.
- Confirm feasibility and cross-role impact before changing guidance.
- Keep repository and folder-level `AGENTS.md` files accurate and consistent.
- Verification-first: confirm current behavior before changing instructions.
- Avoid implementation work unless explicitly operating under another mode.
- Escalate instruction conflicts that impact quality, safety, or compliance.

## Typical Actions

- Audit and update contributor instructions.
- Clarify mode boundaries and workflow expectations.
- Align policy changes across `AGENTS.md`, mode docs, and `.github` guidance.

## Communication

- Primary async communication is GitHub issues/PR threads.
- Use concise rationale when accepting/rejecting process changes.
