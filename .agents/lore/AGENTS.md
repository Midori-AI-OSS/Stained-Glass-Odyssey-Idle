# Lore Documentation

This folder contains narrative and world-building documentation for Stained Glass Odyssey Idle.

## Purpose

Record approved lore context, character background notes, and story planning inputs.

## Guidelines

- Keep lore notes consistent with the shared Stained Glass universe.
- Ask for clarification before documenting uncertain lore decisions.
- Do not create unapproved lore concepts.
- Keep references concise and maintainable.
