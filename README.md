# Stained-Glass-Odyssey-Idle
A game based on our Stained Glass games using chars from the shared world.

## Try It Out
- Main:
  `uvx --from "git+https://github.com/Midori-AI-OSS/Stained-Glass-Odyssey-Idle.git@main" python -m endless_idler`
- Nightly:
  `uvx --from "git+https://github.com/Midori-AI-OSS/Stained-Glass-Odyssey-Idle.git@nightly" python -m endless_idler`

Requires `uv` and `git`.

## Run (dev)
Use `uv` to run the PySide6 UI:

- `uv run main.py`
